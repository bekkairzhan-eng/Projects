# ТЗ для фронтенд-разработчика — BILife Portal
**Версия:** 1.1 | **Дата:** июнь 2026

Прототип реализован на **React + Vite + Tailwind CDN**.
Этот документ описывает поведение, состояния и логику каждого компонента.

---

## 1. Стек и дизайн-система

- **React 18**, Vite
- **Tailwind CSS** (CDN, кастомные токены)
- **Material Symbols Outlined** — иконки
- **Inter** — шрифт
- Цветовые токены: `primary: #002068`, `error: #ba1a1a`, `surface-container: #eeedf6`

### Поведение
- **Раскрытие подпунктов** — клик на родительский пункт toggle expand, стрелка rotate(180°)
- **Активный пункт** — bg-primary-container + border-l-4 + иконка в заливке (FILL 1)
- **Активный дочерний** — синий текст + точка справа + иконка в заливке, родитель тоже подсвечивается
- **Сворачивание** — кнопка-кружок на правом краю (w-6 h-6), ширина 256px → 72px, transition 300ms
- **Свёрнутый режим** — только иконки, tooltip через `title`, бейджи как точки
- **Автосворачивание** — при открытии iframe (Unity BPM / BILIM) сайдбар автоматически сворачивается

### Счётчики
Получать из `GET /api/counters`. Обновлять при:
- Первой загрузке страницы
- Выполнении задачи пользователем
- Получении нового уведомления (если используется WebSocket)

## 5. Main Content — Главная страница

### 5.1 Мой день

Три карточки: **Активные / Ждут меня / Закрыто**

| Карточка | Данные | Поведение |
|----------|--------|-----------|
| Активные | `tasks?status=active` → `total` | Клик → ничего (пока) |
| Ждут меня | `tasks?status=waiting` → `total` | Клик → открыть Tasks Drawer |
| Закрыто | `tasks?status=completed` → `total` | Клик → ничего |

**Ждут меня = 0** → кнопка некликабельна, курсор `default`, цифра серая.

### 5.2 Новости

**Вкладки:** Лента / Новости / Предложения / Опросы
- Активная вкладка: bg `#002068`, белый текст
- Переключение вкладки: перефильтровать данные, featured = первый `featured: true` в выборке

**Карточки:**
- **Featured (левая, md:col-span-2)** — h-200px изображение + заголовок + текст + теги + «Читать →»
- **Secondary (правая, 3 штуки)** — горизонтальная: картинка 100×80 + категория + заголовок + дата, `flex-1` для выравнивания высоты

**Пагинация:** кнопки «Все», «←», «→» в шапке секции

### 5.3 BI Дауысы

- **Бесконечная прокрутка** внутри карточки (max-h-480px, overflow-y-auto)
- IntersectionObserver следит за sentinel-элементом в конце списка
- При появлении sentinel в viewport → догрузить следующие N постов из API
- Когда данные кончились → sentinel скрыть, не запрашивать
- **Лайк** — красный `favorite` icon, заливка при активном состоянии, счётчик обновляется оптимистично
- **Фото-индикатор** — иконка `photo_camera` + число если у поста есть вложения
- **Клик на «N ответов»** → открыть полную страницу поста (следующая итерация)

### 5.4 Быстрый запуск

6 кнопок в сетке 2×3: Фонд Жулдызай / Service Desk / Записка / Договор / На отпуск / Доступ
Клик → открыть соответствующий процесс в BPM (следующая итерация)

### 5.5 Мое обучение

Прогресс-бары курсов из BILIM API. Кнопка «Продолжить курс» → открыть BILIM в iframe.

### 5.6 Дни рождения

- Горизонтальная сетка, 10 карточек на страницу, `grid-template-columns: repeat(10, 1fr)`
- Пагинация: «Все» + «←» + «→» в заголовке секции
- Сегодняшние именинники: синяя рамка + голубой фон + бейдж 🎂
- Кнопка «Поздравить» → (следующая итерация — отправка поздравления)

### 5.7 Клубы BI

- Сетка `repeat(5, 1fr)`, фиксированная
- Логотипы: `/club1.png` … `/club5.png`, объект-fit contain, высота 56px на фоне цвета клуба
- Клик → (следующая итерация — страница клуба)

## 6. Right Panel

Фиксированная панель, `w-80`, видна только `xl:flex`.

### 6.1 Задачи

- Показывать первые **3 задачи** из `GET /api/tasks?status=active&limit=3`
- Кнопка **«Все (N)»** → открыть Tasks Drawer
- N = `total` из API ответа

**Карточка задачи:**
```
[Статус-бейдж] [Номер документа]   [Дата]
Название процесса
[Согласовать] [Отказать]
```

**Цвета статусов:**
| Статус | Цвет текста | Фон |
|--------|-------------|-----|
| Согласование | #1d4ed8 | #eff6ff |
| Подписать | #0f766e | #f0fdfa |
| Исполнить | #b45309 | #fffbeb |
| Ознакомиться | #6d28d9 | #f5f3ff |
| Пройти опрос | #be185d | #fdf2f8 |

**Кнопки действий:**
- Положительное действие (Согласовать / Подписать / etc.) → зелёный `#16a34a`
- Отказать → тусклый красный `border: #f87171, color: #dc2626, bg: #fff5f5`

### 6.2 Моя команда

- Данные из BPM (матрица подчинённости) через `GET /api/team`
- Показывать всех (без кнопки «Все»)
- **Клик на сотрудника** → открыть карточку сотрудника. Маппинг по GUID физлица — единственный идентификатор пользователя в системе.

### 6.3 Слово дня

- Данные из `GET /api/word-of-day`
- Тёмный фон `#0d1f4e`, белый текст
- Если текст длинный — карточка растягивается, панель прокручивается

## 9. Детальная карточка задачи

Открывается при клике на задачу в drawer. Вариант реализации: **модальное окно поверх drawer** или **отдельная страница**.

### Содержимое
```
[Источник-бейдж]         [Статус]
Название процесса
№ документа · Дата создания · Срок: ДД.ММ.ГГГГ

Поля процесса (из fields[]):
  Период:           Май 2026
  Подразделение:    ДС Цифровые сервисы
  Сумма:            150 000 ₸

Вложения:
  📎 табель_май.pdf   [Скачать]

Комментарий (textarea, опционально)

[Отказать]    [Согласовать]
```

### Кнопки действий

**Согласовать / Отказать / Исполнить / Ознакомиться:**
1. Клик → `POST /api/tasks/{id}/action { action: "..." }`
2. Показать лоадер на кнопке, задизейблить обе кнопки
3. Успех → закрыть карточку, обновить список, обновить счётчик в сайдбаре
4. Ошибка → `toast` с текстом ошибки, кнопки снова активны

**Кнопка «Открыть в [Система]»**

Показывается в карточке задачи всегда (кроме задач из 1С HRMS).

| Источник | Кнопка | Поведение |
|----------|--------|-----------|
| unity_bpm | «Открыть в Unity BPM» | Открыть `deep_link` в iframe (как при клике на систему в сайдбаре) |
| bagdar | «Открыть в Bagdar» | Открыть `deep_link` в новой вкладке |
| bilim | «Открыть в BILIM» | Открыть `deep_link` в iframe |
| 1c_hrms | — | Кнопку **не показывать** (система работает в терминале) |

**ЭЦП — полностью на стороне Unity BPM.**
Пользователь нажимает «Открыть в Unity BPM» → подписывает там через NCALayer.
BILife никак не участвует в процессе подписания — только получает `task.completed` webhook и обновляет счётчик.

## 10. Iframe-режим (Unity BPM / BILIM)

При клике на систему в сайдбаре:
1. Сайдбар автоматически сворачивается (72px)
2. Main content + Right Panel скрываются
3. Показывается iframe на всю доступную высоту
4. Топ-бар: «← Назад» + название системы + «Открыть в браузере»
5. Если iframe заблокирован (X-Frame-Options) → показать заглушку с кнопкой «Открыть в браузере»
6. «Назад» → сбросить систему, восстановить main content (сайдбар остаётся свёрнутым)

## 11. Переключатель языка

- 6 языков: RU / KZ / EN / UZ / UA / AZ
- Текущий язык в кнопке, дропдаун при клике
- Закрывается кликом вне
- Выбранный язык: синий код, серый фон строки
- **i18n:** при переключении все тексты интерфейса меняются (интеграция с i18next или аналогом)
- Выбранный язык хранить в `localStorage` и `PATCH /api/settings/language` для сохранения между сессиями (по GUID физлица из сессии)

## 13. Аналитика (трекинг событий)

При каждом значимом действии вызывать:

```js
track(event, category, label)
// POST /api/analytics { event, category, label, page }
```

Ключевые события:
- `page_view` при переходе между разделами
- `task_action` при согласовании/отказе
- `tasks_drawer_open` с источником (виджет/панель/уведомление)
- `news_tab_click` при переключении вкладки
- `quick_launch_click` с названием кнопки
- `notif_news_toggle` при смене чекбокса

Полный список событий — в `ANALYTICS_TZ.md`.
